# MoStaff — paket pemasang

Repo ini hanya berisi berkas pemasang aplikasi desktop MoStaff, di
[Releases](https://github.com/itdepartementisykariman/MoStaff-releases/releases). Kode sumbernya privat.

Unduh lewat halaman unduh organisasi Anda — https://mostaff.isykarimangroup.com/unduh — di
sana ada panduan pasang dan izin untuk tiap sistem operasi.

Berkas `.zip` dan `latest*.yml` dibaca pembaruan otomatis di dalam aplikasi.
Rilis yang sudah terbit tidak pernah diganti isinya: aplikasi yang terpasang
memeriksa sidik SHA-512 setiap berkas.
